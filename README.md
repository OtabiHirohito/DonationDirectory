# DonationDirectory（寄付先一覧）

本プロジェクトは、国際支援や人道支援、子ども・小児医療支援、動物保護活動などに取り組む信頼性の高い寄付先団体の情報をわかりやすく掲載しています。

※掲載している各団体は本ページの制作者と一切関係がありません。

## 🔗公開ページ
[https://OtabiHirohito.github.io/DonationDirectory/](https://OtabiHirohito.github.io/DonationDirectory/)

## 主な機能

- **寄付先団体一覧・詳細情報**
  各団体の「活動内容」や「寄付金の使い道」を分かりやすくまとめています。
- **サイドバー目次 & スクロールスパイ**
  画面左側のナビゲーションメニューから目的の団体へスムーズにスクロール移動できます。現在の表示位置に合わせて目次が自動ハイライトされます。
- **ランダム寄付先ジャンプ**
  「ランダムで寄付先へジャンプ」ボタンを押すと、掲載されている寄付先ページの中からランダムで1つを選んで開きます。また、`random.html` または `index.html?random` を開くと、直接自動でランダムな寄付先へジャンプします。

## ファイル構成

- `index.html` - メインのWebページ（構造・コンテンツ・目次ナビゲーション）
- `random.html` - ランダム寄付先直飛び用ページ（開いた瞬間に自動でランダムな寄付先へリダイレクト）
- `style.css` - デザインスタイル（レスポンシブ対応・ダークモード等）
- `script.js` - インタラクティブ機能（スクロールスパイ、ランダムジャンプなど）

## 閲覧・利用方法

Webブラウザで `index.html` を開くことでご利用いただけます。特別なビルドプロセスや外部サーバーは不要です。
直接ランダムな寄付先を開きたい場合は `random.html` にアクセスしてください。
